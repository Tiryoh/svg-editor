# SVG Editor

SVGの確認・編集ツール。ブラウザ上でSVGファイルを読み込み、要素の検査・編集・クリーンアップができます。

## セットアップ

```bash
npm install
npm run dev
```

## プレビューの操作方法

### macOS（トラックパッド）

| 操作 | 動作 |
|---|---|
| 2本指スクロール | パン（表示範囲の移動） |
| ピンチイン/アウト | カーソル位置を中心にズーム |
| Space + 左クリックドラッグ | パン |

### Windows / マウス

| 操作 | 動作 |
|---|---|
| ホイール回転 | パン（上下移動） |
| Ctrl + ホイール回転 | ズーム |
| 中クリック + ドラッグ | パン |
| Space + 左クリックドラッグ | パン |

### 共通

| 操作 | 動作 |
|---|---|
| 右下の `-` / `+` ボタン | ズームイン/アウト |
| 右下のパーセント表示をクリック | 表示をリセット（100%） |
